Epic 7 looks

Code-drawn proposals for every Epic 7 screen and the loot bag. Pick one code per item (e.g. "RW1, PH1, BT2 …"), or just say "ok" for all the recommended ones (green border).

Every screen is drawn at the real phone size in CSS px (568 × 320 iPhone with its 44 / 21 px safe edges hatched in green, and 800 × 360 Android), styled by the game's own overlay.css. Survivors, weapon / gear / building icons and the street are the game's own drawing code (drawSurvivor with the Story 7.8 parts, the shop icons, the Downtown bake), bundled into this page. Buttons are ≥ 44 px, text ≥ 14 px. Colour rule kept: red = boss danger only, amber = an event you can use, yellow-green = gas, white = pick-ups and people. Many frames can be tapped (tabs, Unlock, editor tiles).
