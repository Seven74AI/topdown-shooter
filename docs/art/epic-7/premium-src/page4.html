Lumen · colour themes

The designer chose Lumen (PI1) as the Epic 7 interface language and asked to try other colour themes. Construction, components, layout and motion are identical; only the palette changes, so the themes compare 1:1. Each is shown on the DW1 dawn (568 × 320 Extract) and the DW2 blue hour (800 × 360 endless).

Colour rule checked per theme (designer update: red is allowed on menu screens; red = boss danger applies to play only, and LR4 tries it); amber = an event you can use; yellow-green = gas; white = pick-ups and people; player slot colours (blue / orange / green / purple) stay distinct from the accent; rarity framing (new item / found / teammate's find / Collector) still reads. Canvas 2D, game code only, Oswald embedded; ?static or reduced motion stops motion.

No pick yet: tap LG0, LC1, LP2, LT3 or LR4.

Performance (Xiaomi Mi 11i): every plate, texture, backdrop and item close-up is rendered once into a canvas (in the game: baked textures, like hudWarnArt.ts); per frame only the counter digits, one sweep band, a few glow strokes and the scroll offset change. One full-screen frame here ≈ 1–2 ms on a desktop; motion stops entirely with reduced motion. Source: docs/art/epic-7/premium-src/.
