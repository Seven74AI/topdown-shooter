Meshy vs Claude

Same descriptions, three makers. 1. Meshy: AI image, ≈ 9 credits each. 2. Claude, vector illustration: a picture written by hand as SVG, free. 3. Claude, game code: drawn live by the game (how the bus and cars are made today), free, any size, easy to change. The strip under each card shows all three at real in-game size.

Code drawings use only Canvas 2D: paths, gradients, small noise patterns. No images, no libraries.
