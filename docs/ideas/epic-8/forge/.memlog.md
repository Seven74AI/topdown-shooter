- (note) Personas: Cloud Dragonborn (game architect), Samus Shepard (game designer), generated: Theo (plays on the train, signal drops every tunnel), Rina (min-maxer who looks for exploits).
- (assumption) Code check: today every disconnect is onLeave: player removed from World and state at once; host already migrates to the longest-connected member (lobby.ts nextHost). So 8.3 is mostly built.
- (crack) Theo: remove-from-World on drop is safe, but if the last connected player drops (solo, or everyone in a tunnel) the room auto-disposes and the run is gone. Fix: freeze the World while nobody is connected, up to the 120 s hold.
- (crack) Rina: dropping while downed and coming back 'with the HP you had' next to a teammate is a free revive/teleport. Fix: dropped while downed = out for this wave (back at the next build, like any out player).
- (crack) Rina: after 120 s a return is a 'new join' with the team average money: a broke player could quit and rejoin to get fresh cash. Fix: remember every seat for the whole run by account; a returning account always gets its own stuff back, never a fresh joiner's.
- (crack) Samus: average WALLET right after a big shop is near zero, so a late friend gets ~50 and a Pistol at wave 7. Fix: base it on what teammates EARNED (player.earned exists): 100 + 60 % of the team's average earned.
- (crack) Samus: a friend who joins with 5 s left on the 30 s build timer can't shop. Fix: a join adds +15 s to the timer, once per build phase.
- (crack) Cloud: host = who taps Start / Save. With saves owned only by the host account, a migrated host's run is unresumable for the original group. Fix: a saved run belongs to every account that was in it; any of them can resume.
- (crack) Cloud: autosave at build START loses all the shopping if the server crashes mid-wave. Fix: also snapshot on the last build tick (wave about to start); keep only the newest.
- (crack) Rina: everyone closes the app mid-wave just before a wipe, then resumes the autosave = free retry. Fix: only a server-side stop (crash, deploy) makes an autosave resumable; players all leaving mid-wave ends the run as lost.
- (crack) Cloud: every deploy bumps the balance version; if that blocks resume, every save dies on release day. Fix: balance changes never block a resume; only a snapshot schema bump does, and each bump ships a migration (CI test).
- (crack) Rina: rejoin to reset reload, consumable gap or shop reroll. Fix: everything is held exactly (mag, reload restarts from 0 not full, consumable count, current card offer).
- (decision) Pings: rename 'Brute!' to 'Big one!' so it covers the Behemoth; pinned where sent, 4 s, one live ping per player, 1/s.
- (decision) Accepted risk: a mid-wave return appears next to a standing teammate (a small teleport); costs 5-10 s of reconnect time, so not worth a rule.
- (lock) All recommendations go to the designer as D1-D15 in docs/ideas/epic-8/decisions.md; designer answers ok or codes.
